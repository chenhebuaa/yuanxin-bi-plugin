# 原心 BI · Codex 插件

通过飞书登录，查询已发布的品牌调研数据，并比较两个品牌的指标。数据在原心 BI 服务器中处理，插件提供品牌/批次检索、品类与标签查询、单品牌查询、双品牌对比和数据版本查询。

## 品牌品类与窄门标签

品牌查询和双品牌对比会同时返回：

- **人工品类**：如正餐、休闲简餐、快餐、小吃。
- **窄门标签**：支持多个标签，保留人工标注原文。
- **统一品牌名称**：关联同品牌的地区、年份及调研批次，各批次问卷数据仍独立。
- **匹配状态与来源**：保留窄门匹配品牌名、疑似/未匹配状态、备注和标注表来源。

人工品类与窄门标签分别呈现；疑似或未确认的窄门匹配不等于标签已由窄门核实。未标注的品牌显示缺失，不自动推断。数据覆盖范围以服务返回的最新版本为准。

## 安装

在已安装 Codex CLI 的终端执行：

```sh
codex plugin marketplace add chenhebuaa/yuanxin-bi-plugin --ref v0.1.1
codex plugin add yuanxin-bi@yuanxin-bi
codex mcp login yuanxin-bi --scopes bi:read --oauth-client-registration dcr
```

按浏览器提示用飞书登录，随后新建 Codex 任务并启用「原心 BI」。需要支持远程 HTTP MCP、插件市场与 OAuth DCR 的 Codex 版本；命令不识别时先更新客户端。

### 示例

- 查询某个品牌的调研份数、性别比例，并注明调研日期和来源。
- 对比两个品牌的复购和渠道指标，并列出差异。
- 列出一个品牌的所有调研批次，让我选择。
- 查询某品牌的人工品类、窄门标签及匹配状态。
- 列出已标注为“休闲简餐”的品牌，保留地区和调研批次。

同名品牌存在多个批次时需先选择。比例差值使用百分点；不同日期的横向比较不代表时间趋势。缺失及异常原值不按零处理。

## 准入与隐私

安装包公开，数据访问仅向获准的公司成员开放。每次请求由服务器校验飞书租户、有效会话和白名单；安装插件不自动获得数据权限。管理员和已加入白名单的同事可以访问；新同事还需在飞书应用可用范围内。

访问令牌有效期 1 小时，过期后按提示重新登录；当前不提供自动续期。服务地址为 `https://bi.yuanxininsight.com/mcp`。本仓库仅分发插件，不包含问卷原文件、查询结果、服务端代码、飞书密钥或令牌。查询返回的数据会进入使用者的 Codex 会话。

## 更新与版本

当前说明版本为 `v0.1.1`，固定标签用于可重复安装，已发布的标签不移动。新版本发布时提供对应安装命令与变更说明；固定旧标签的安装不会自动切到新标签。

本机若已安装早期 `yuanxin-bi@personal`，先移除该本地插件，再从此 GitHub 市场安装，避免出现两个同名 MCP 服务：

```sh
codex plugin remove yuanxin-bi@personal
```

该命令只用于已安装本地开发版的用户。移除后执行上面的安装步骤。
